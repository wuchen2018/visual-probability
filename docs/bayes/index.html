检测阳性，患病的概率就是99%吗？

比如你去医院做了一项罕见病检测。听说检测号称“99%准”：真正患病的人里，99%能测出阳性；没病的人里，1%会被误判成阳性。结果单子一出来：阳性。你可能会想，那我有99%的概率真的得病了吧？

假如参加检测的人里，只有0.1%原本患病，阳性后真正患病的概率其实还不到10%。为什么差这么多？我们让10万人一起参加检测，把阳性的人分成“确实患病”和“被误判”两组，数一数就知道了。下面的人群患病比例和检测准确率都可以改。
