图中选中的人，具体是什么情况？

拖动虚线上的绿色菱形、虚线本身或上方滑块，就能改变门槛。点击一个点，橙圈会标出这个人，分数和入选原因显示在你点击的图下。也可以先点图，再用方向键调整门槛。

图里的主体是电脑随机生成的700个普通人物，另外特意固定放进4个“40分、80分”的典型对照人物，加起来共704人，方便你点击比较谁留下、谁被刷掉。两项分数都在0—100之间。拖动筛选线时，每个人的分数和位置都不变，变的只是谁能进入筛选图。

这条线怎样决定谁会出现？

棕色实线根据各自图里的点计算，概括整群点的倾斜方向；虚线由你设置的门槛决定。你可以取消“显示趋势线”，只看人物和筛选过程，也可以换一组模拟人物再试。
