先用一组简单的数算一遍

假设某次测量的平均数恰好是170.2厘米。下面只用这个例子看算法，不把它计入上面的随机实验。

① 平均数会波动多大？

一个人的身高标准差是6厘米；一组人的平均数波动更小。这个平均数的标准差叫“标准误差”，等于6除以人数的平方根。

② 在平均数两边各加多长？

先按置信水平选一个倍数，再乘标准误差，就得到区间的单侧宽度。这个倍数记作z。

③ 把区间两端算出来

用170.2减去这段长度，再用170.2加上这段长度，就是区间的两个端点。

为什么95%会用到1.96？

在这个正态身高模型中，一组人的平均数也服从正态分布。平均数离真实均值不超过1.96个标准误差的机会约为95%。两者的距离相同：平均数离171不超过这段长度，也就等于以平均数为中心画出的区间包含171。

标准正态曲线中间90%、95%、99%的面积，分别对应左右约1.645、1.96、2.576个标准差。本页采用这三个取近似后的倍数，下面的乘法按列出的倍数计算。

试两次，就能看出宽度怎样变

先保持每组36人，把90%改成99%。身高记录没有变，横线会变宽，原来没覆盖171的某些区间就能覆盖了。置信水平提高，代价是给出的范围更宽。

再保持95%，比较每组9人和36人。人数变为4倍，标准误差从6÷3＝2厘米降到6÷6＝1厘米，单侧宽度也从3.92厘米降到1.96厘米。多测量一些人，才能把区间缩窄；当前这批覆盖多少组，仍然由抽样结果决定。
