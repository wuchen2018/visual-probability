10次里9次正面，要怀疑硬币偏心吗？

朋友说这枚硬币公平，你试抛10次，却出了9次正面。这是碰巧运气好，还是硬币真的偏心？先假定每次正反面各50%、各次独立，算一算：如果它真公平，出现这么偏、甚至更偏的结果有多容易。

把“同样偏和更偏”的机会加起来，得到双侧p值。我们先选好一条判断门槛，再看这批结果是否足以让人怀疑“硬币公平”。这个起初拿来检验的说法，叫原假设，写作H₀。

至少撞出一次误报的机会，多大？

每轮都先按同一规则检验，整批“至少出现一次显著”的机会却会随着轮数增加。若反复测到显著才停，再把最后一轮当作唯一的一轮报告，原来的单轮风险上限就管不住这套筛选过程了。

误拒公平硬币，和漏掉偏心硬币

把公平硬币判成偏心，叫第一类错误；硬币实际偏心却没有拒绝公平假设，叫第二类错误。两者要在各自的真实情况中计算，不能把当前p值直接当成犯错概率。

上面拿公平硬币测试，是看会不会冤枉它。下面反过来：先亮出一个我们平时不知道的答案，假设这枚硬币确实偏心，比如正面概率是70%，再算刚才的门槛有多大机会把它找出来。这只是用已知真值检查方法，不会改动上面的公平硬币模拟。

p值和门槛，各自在说什么？

p值先假定H₀成立，再算当前这样极端的记录出现的概率。计算方向是“假设公平→看极端记录”；把它读成“公平的概率”，就把问题倒过来了。

α是事先给检验规则定的误报上限。硬币计数只能取整数，可用的拒绝范围是一档一档变化的；门槛从5%改到10%，本页这两种样本量的拒绝范围都恰好不变。看当前列出的拒绝次数和实际误报率，能直接核对。

降低门槛通常会少误报，也更容易漏掉偏心硬币；增加每轮抛掷次数，可以给判断提供更多信息。多测几轮再只挑最好看的一轮，会增加另一种风险。
