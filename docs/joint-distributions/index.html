两件事缠在一起，怎么单独看其中一件？

平时坐公交通勤，总有两笔时间脱不开关系：你在站台干等了多久（X），以及上车后在路上坐了多久（Y）。如果公司记下了100个人各自搭车的时间，手头就有了一张“候车和车程同时出现”的联合统计表。

但很多时候你只想知道其中一个问题——比如“大家平时等车各占几成”，或者“既然今天已经在站台等了10分钟，上车后大概要坐多久”。下面可以改改九种组合里的人数，看看怎样从同一张联合表里，分别挑出各自的边际分布和已知条件后的条件分布。

最后再看一个连续取值的例子：当数值连成一片、没法数人头时，怎样用一条竖带再逐渐缩窄，理解边际与条件密度。
