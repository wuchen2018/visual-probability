六个竖直差，为什么要先平方？

预测值记作Ŷ，“Y上加一个帽子”，用来区别真实成绩Y。残差＝Y−Ŷ，表示预测差了多少分；正负误差直接相加会抵消。先平方再加，每一项都不会小于0，得到残差平方和SSE，单位是分²。

最小二乘法，怎样把两个系数算出来？

先求数据的平均位置。X偏离就是X减平均小时数，Y偏离就是Y减平均成绩。固定斜率，只上下移动直线，让平均预测等于平均成绩，就能去掉整体偏高或偏低的误差；这要求直线经过重心。斜率由两种偏离的乘积和，除以X偏离的平方和得到。
