分着比都赢，合起来反而输了？

假设你要比较两种治疗肾结石的方案：A是传统开放手术，B是新型微创手术。两种方案各治疗了350名患者。我们按结石大小，把患者分成小结石和大结石两类。

成功率就是“成功人数÷治疗人数”。两种方案的治疗记录如下：

289÷350 ≈82.57%

只看小结石，方案A的成功率更高，93.10%对86.67%；只看大结石，还是方案A更高，73.00%对68.75%。合起来算总账，方案B却以82.57%超过了方案A的78.00%。

这怎么可能？这也太奇怪了吧！只看小结石A更高，只看大结石也是A更高，合起来怎么反而比B低了？

看看两边各自接收了什么病人：传统手术A接了263名大结石患者，新型微创B却接了270名小结石患者。大结石本来就更难治好，在两种方案里的成功率都更低。两边面对的病人轻重差了这么多，是怎么把整体成功率给反过来的？你可以自己改改下面两边接收的人数，看看结果怎样变化。

先分开算：同样大小的结石，哪种方案成功率更高？

比如A治疗小结石的成功比例是81÷87。换一批人数，只要沿用这个比例，就用“当前人数×81÷87”推算预计成功人数。算出的小数表示平均预计人数；后面的合并计算都用未四舍五入的数值。

再合起来算：成功人数相加，除以总人数

每种方案都把自己的两类患者合并。下面整条仍是350人，绿色、棕色只画两类患者中预计成功的人，灰色合并两类中未成功的人。参数区的色条画的是全部小结石、大结石患者。

同一类患者里A都更高，为什么合并后可能反过来？

刚才先把两类成功人数加起来，再除以350。也可以让两类成功人数各除以350，再相加，结果相同。

每一类的成功人数都是“这一类的人数×成功率”。再除以总人数350，就得到“成功率×这一类的人数占比”。

左边是小结石成功人数除以总人数；右边是小结石成功率乘以小结石人数占比。大结石也这样算，两类相加就得到：

小结石成功率×小结石人数占比
＋大结石成功率×大结石人数占比

这个人数占比，就叫作“权重”。病例越多的那一类，对整体结果的影响越大。

先分组算成功率，再按各组人数占比相加，这就是全概率公式在这个例子里的用法。

比较整体成功率时，先看看两边小结石、大结石各占多少。让病例构成相同以后，才能看清这组数据里两种方案的成功率差别。
